# bosonoise

First-principles noise channels of bosonic-qubit cells: **circuit → spectra → dynamics → channels → detector error
models**.

This repository holds the code and the data products of the paper

> **Photon-stimulated decay of χ-matched ancillas causes unheralded bit flips in bosonic codes** (2026). The arXiv
> identifier will be added here.

Every figure and table of the paper is reproduced by one command (see [Reproducing the paper](#reproducing-the-paper)).
Version 0.1.0; see `CHANGELOG.md`.

## The result in brief

- Bosonic codes often read their syndrome out through a transmon ancilla whose computational levels g and f have equal
  parity and matched dispersive shifts (χ-matching). A decay f → e is then heralded and leaves the code intact, while
  the direct f → g is forbidden by parity.
- The photons of the code open this decay at first order in the ancilla's decay rate. Dressing by the code mode lets the
  charge noise that limits the ancilla's T1 drive a photon-stimulated Raman decay |f,n⟩ → |g,n+1⟩, at
  (n+1)(χ_ge/2g₀₁)² times the f → e rate for a smooth noise spectrum, i.e. a branching per photon
  ρ ≈ |χ_ge|α / (2|Δ(Δ+α)|) (paper Eq. (3)).
- When the matching is set by the detuning, the decay costs ≈ Γ_fe/α per gate and photon, whatever the coupling
  strength. A deliberate mismatch or matching by a drive lowers this cost; a qubit ancilla (g, e) has no such channel.
- The opened decay is unheralded and flips a cat with probability ≈ 1/2. Being first order, it overtakes the
  second-order double decay f → e → g as the ancilla improves.
- In a microscopic model of the Ocelot repetition cat code (Putterman et al., Nature 638, 927 (2025),
  arXiv:2409.13025), it makes the bit-flip floor of the gates grow linearly with the cat size, by a factor 1.2–1.7
  from four to ten photons, which would limit the noise bias to ~10³. The published gate data end at four photons and
  do not yet test this growth.

## What is inside

- **Cells from the circuit.** Charge-basis transmons with the full cosine, and storage–coupler–ancilla cells in the lab
  frame (no RWA). They are calibrated to static spectroscopy only, never to error rates.
- **The bit-flip channel of the syndrome cycle.**
  - Dressed-ladder CX² simulations with the universal Lindblad equation.
  - Stabilizer fault tables.
  - The conversion of ancilla faults into cat bit flips, with heralds.
  - Stabilization windows and ensembles of two-level defects (TLS).
- **The GKP cell.** Floquet branches and Floquet–Markov rates of a transmon driven by a displaced cavity.
- **Stim.**
  - Repetition cat code memories with heralds and leakage.
  - Three reference noise models: Ocelot-type hybrid, all-cat in the style of Alice & Bob, and Kerr cats. Every
    parameter has a provenance.
  - 72 syndrome datasets.
- **One command per figure.** `tools/reproduce.py` regenerates every figure and data product.

## Install

Python 3.10 or newer:

```bash
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e ".[dev,qec,data]"
pytest                                            # 95 tests, about a minute
```

Extras:
- `qec`: stim, PyMatching, sinter (Stim circuits, decoding);
- `dev`: pytest, scqubits, qutip (tests, cross-checks and the two-mode models of the stabilization);
- `data`: pyarrow, for the public Ocelot data;
- `tools`: pdfminer.six, to re-extract the digitized figures from the arXiv PDFs.

## Quick start

A reference noise model, sampled with leakage and decoded:

```python
from bosonoise.dem.models import kerrcat_model
from bosonoise.dem.noise_models import decode_memory, sample_with_leakage

noise = kerrcat_model(nbar=6.25, d=5)          # the DA21 design point; noise.provenance names a source per number
out = sample_with_leakage(d=5, rounds=5, noise=noise, shots=10_000, basis="X", seed=1)
pred = decode_memory(out["circuit"], out["detectors"])            # PyMatching on the circuit's DEM
print((pred[:, 0] != out["observables"][:, 0]).mean())            # logical phase-flip failure, about 4%
```

A stored syndrome dataset (see `data/syndromes/README.md`):

```python
from bosonoise.benchmark.schema import read_dataset

ds = read_dataset("data/syndromes/ocelot_nbar2_d5_X")   # detectors, observables, heralds, leakage, metadata
```

## Reproducing everything

```bash
python tools/reproduce.py --list                     # 103 targets: every figure and every data product
python tools/reproduce.py fig7_ocelot_reproduction   # one target
python tools/reproduce.py --all --max-minutes 15     # every target that takes at most 15 min (85 targets, ~4 h)
python tools/reproduce.py --missing                  # targets whose external inputs are absent
python tools/compare_to_git.py                       # compare regenerated data with the committed files
```

All targets together take about 15 hours on a 4-core laptop, one core per target. Fifteen of them need external inputs
that are not in the repository: the arXiv PDFs of the Ocelot and companion papers (only to re-extract the digitized
figures) and the public Ocelot data archive (Zenodo 10.5281/zenodo.14257632). `docs/reproduction.md` explains how to
obtain them and lists every target with its command, outputs, external inputs, dependencies, runtime and redraw mode.

## Data

- `data/calibration/`: static calibrations of the Ocelot cells (paper App. A).
- `data/digitized/`: numbers extracted from figures of the Ocelot and companion papers (third-party data, see below).
- `data/validation/`: every model-versus-data and model-versus-literature comparison.
- `data/branches/`, `data/atlas/`, `data/apt/`, `data/tls/`: spectra, the crossing atlas, flux-ramp scans and defect
  statistics.
- `data/syndromes/`: 72 syndrome datasets of the three reference noise models (`data/syndromes/README.md`).

## Layout

```
src/bosonoise/
  model/      charge-basis transmons (full cosine), storage-coupler-ancilla cell (lab frame, no RWA)
  spectra/    dressed states, dispersive observables, calibration to static spectroscopy, branch analysis, crossing atlas
  dynamics/   flux pulses (irrotational gauge), time-dependent cell, universal Lindblad equation, adiabatic perturbation
              theory, Floquet branches and rates
  channels/   CX^2 and syndrome-cycle fault models, conversion map and heralds, stabilization windows, TLS, baselines
  dem/        Stim circuits of the repetition cat code with heralds and leakage; the three reference noise models
  benchmark/  on-disk format 0.1 of syndrome datasets (Stim b8 + JSON metadata)
  presets/    device parameters (Ocelot, companion device) and literature operation models (all-cat, Kerr-cat),
              every number with its source
examples/     one script per figure or data product
tools/        extraction of published figures, the Ocelot noise table, reproduce.py, compare_to_git.py
tests/        pytest suite
data/         calibrations, digitized figures, atlas, validation tables, syndrome datasets (data/LICENSE.md)
figures/      every figure (regenerated by tools/reproduce.py); prx_* are the figures of the paper
docs/         reproduction guide
```

## Conventions

- Frequencies are f = ω/2π in GHz (h = 1) and times are in ns, unless a name says otherwise.
- Transmon-like elements are always treated in the charge basis with the full cosine. There are no Duffing or
  two-level truncations and no adiabatic elimination of the coupler.
- No parameter is ever tuned to error-rate data. Published error rates and the public data are used only for
  validation, and data-anchored variants are labelled as such.
- Every number carries a provenance: `presets/`, the dataset metadata, and the docstrings of the scripts, which cite
  the paper as "paper Sec. 4", "paper App. D", "paper Eq. (5)" or "paper Fig. 1".
- The variant `zero-fit` of the scripts and data tables is the *idle-referenced* bath of the paper; `lam3` and
  `lambda3` stand for λ = 3, the on-gate enhancement of the decay rates.
